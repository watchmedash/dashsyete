# Dash City Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Browser-based multiplayer car-combat arena: 4 teams knock each other out in a Kenney-asset city, with bots, HP damage, and dual leaderboards.

**Architecture:** Server-authoritative Rapier physics on Node (60 Hz tick, 20 Hz snapshots) with thin `ws` protocol; Three.js client interpolates remote cars ~100 ms behind and predicts the local car in a mirror Rapier world. All game rules, tuning constants, and the city map live in `shared/` so client and server can never disagree.

**Tech Stack:** TypeScript everywhere. Client: Three.js + Vite. Server: Node + `ws` + `@dimforge/rapier3d-compat`. Tests: Vitest. Dev runner: `tsx watch` + `concurrently`.

**Spec:** `docs/superpowers/specs/2026-07-12-dash-city-design.md` — read it before starting.

## Global Constraints

- Single root `package.json` (no workspaces). Folders: `client/`, `server/src/`, `shared/src/`. Shared code imported by relative path; `tsconfig` uses `"moduleResolution": "Bundler"` so imports need no `.js` extension.
- One Rapier version everywhere: `@dimforge/rapier3d-compat` (WASM-inlined, works in Node and browser). It initializes async: every entry point must `await RAPIER.init()` before creating a world.
- All gameplay numbers (HP=100, respawn 3 s, spawn protection 2 s, regen after 6 s, bots 5/team, tick 60 Hz, snapshot 20 Hz, interpolation delay 100 ms) live in `shared/src/constants.ts` — never inline them.
- Teams are `0|1|2|3` = Crimson `#e23b3b`, Azure `#3b7fe2`, Emerald `#3be26b`, Violet `#a03be2`.
- Same-team collisions deal zero damage. Only car-vs-car impacts deal damage. Walls/props/train deal none.
- Clients send only inputs (clamped to [-1,1] server-side); never positions.
- Assets are served from `client/public/assets/` — populated by `npm run assets` (copy script). Never reference the `kenney_*` source folders at runtime.
- Kenney city/road/graveyard/train/watercraft models are unit-tile scale → scaled ×12 (`TILE = 12` world units/meters per tile). Car models scaled ×2.2 (≈4–5 m long).
- Commit after every green test cycle. Windows dev machine: commands must work in PowerShell.

```ts
import { DAMAGE_MIN_SPEED, DAMAGE_PER_SPEED, DAMAGE_CAP } from "./constants";
import type { TeamId } from "./types";

export function impactDamage(relSpeed: number): number {
  if (relSpeed < DAMAGE_MIN_SPEED) return 0;
  return Math.min(DAMAGE_CAP, (relSpeed - DAMAGE_MIN_SPEED) * DAMAGE_PER_SPEED);
}

export function damageBetween(teamA: TeamId, teamB: TeamId, relSpeed: number): number {
  return teamA === teamB ? 0 : impactDamage(relSpeed);
}
```

```ts
import type { TeamId } from "./types";

export function pickTeam(
  humanCounts: [number, number, number, number],
  rand: () => number = Math.random,
): TeamId {
  const min = Math.min(...humanCounts);
  const candidates = [0, 1, 2, 3].filter((t) => humanCounts[t] === min);
  return candidates[Math.floor(rand() * candidates.length)] as TeamId;
}
```

```ts
export function generateBotName(taken: Set<string>, rand: () => number = Math.random): string {
  const pick = (a: string[]) => a[Math.floor(rand() * a.length)];
  for (let i = 0; i < 50; i++) {
    const name = pick(ADJECTIVES) + pick(NOUNS);
    if (!taken.has(name)) return name;
  }
  let n = 2;
  let base = pick(ADJECTIVES) + pick(NOUNS);
  while (taken.has(base + n)) n++;
  return base + n;
}
```

- Produces:

```ts
export type Rot = 0 | 1 | 2 | 3; // quarter turns clockwise around Y
export interface Tile { gx: number; gz: number; rot: Rot; pack: string; model: string; }
export interface BoxCollider { x: number; y: number; z: number; hx: number; hy: number; hz: number; }
export interface CityMap {
  size: number;                       // grid is size x size tiles, world spans [-size*TILE/2, +size*TILE/2]
  tiles: Tile[];                      // visual instances (roads, buildings, props, rails, boats...)
  colliders: BoxCollider[];           // static physics: buildings, walls, fences, arena bounds
  spawns: { team: TeamId; points: { x: number; z: number; rotY: number }[] }[]; // >=4 slots per team
  waypointLoops: { x: number; z: number }[][]; // bot cruising routes along roads
  trainPath: { x: number; z: number }[];       // perimeter rail loop, ordered
}
export function buildCityMap(): CityMap;
export function tileToWorld(g: number, size: number): number; // (g - size/2 + 0.5) * TILE
```

**Layout to implement (24×24 grid):** perimeter ring road at ring index 2 (`road-bend` corners, `road-straight` edges); N–S and E–W central avenues (`road-straight`, crossing the ring at `road-intersection`, meeting at center in a 2×2 `road-roundabout`... the roads pack roundabout is a single tile — place `road-roundabout` at the exact center tile (12,12) area as 1 tile with 4 `road-intersection` neighbors); inside each quadrant a small 2-street grid connecting avenue↔ring. Team spawn plazas: 3×3 `road-square` tiles at the center of each quadrant, 6 spawn slots each facing outward. Quadrant fill per spec themes:

- NW Crimson/Downtown: `commercial` `building-a..n` + `building-skyscraper-a..e` on block tiles adjacent to roads.
- NE Azure/Harbor: `industrial` `building-a..t`, `chimney-large`, `detail-tank`; outside the ring on the NE edge place `watercraft` `ship-cargo-a`, `boat-tug-a`, `boat-speed-a/b`, `boat-fishing-small` on flat "water" tiles (visual only, beyond the arena wall).
- SW Emerald/Suburbs: `suburban` `building-type-a..u`, `tree-large`, `tree-small`, `fence` rows along yards.
- SE Violet/Old Town: `graveyard` `crypt-large` + `crypt-large-roof`, `crypt-a/b`, gravestones (`gravestone-cross`, `gravestone-round`, `gravestone-wide`), `pine`, `iron-fence` border, `lightpost-double`.
- Train: rail loop one ring outside the road ring using `train` `railroad-straight` / `railroad-corner-large`; `trainPath` = ordered tile centers of that loop.
- Colliders: one box per building/crypt/tree-large/boat tile (full tile footprint, height 8–30 by type); low boxes (hy≈1) for fences/walls; 4 arena walls just outside the rail loop (hy=5, thickness 1); NO collider for roads/ground/gravestones/small props (ground itself is one big box added by the physics layer, not the map).
- `waypointLoops`: 3 loops — ring road tile centers (ordered), and two "figure" loops (avenue + half ring each).

Implementation is a deterministic pure function (no randomness — use fixed patterns/modulo so tests are stable). Build helper `addBuildingRing(quadrantBounds, pack, models[])` that walks block tiles adjacent to roads and places `models[(gx*7+gz*13) % models.length]`.
